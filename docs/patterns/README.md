# Patterns

Galeria tecnica de padroes reutilizaveis.

Use esta pasta para registrar decisoes que podem ser reaproveitadas em novos
projetos: paletas, layouts, metricas, funcoes de grafico e convencoes de
saida.

## Regra de promocao

Um prototipo so vira padrao quando:

1. foi aprovado em um projeto real;
2. a logica foi movida para `src/opyta_analysis`;
3. existe uma pagina nesta pasta explicando quando usar;
4. existe pelo menos um projeto de referencia.
