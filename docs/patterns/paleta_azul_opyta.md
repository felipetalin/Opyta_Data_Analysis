# Paleta Azul Opyta

## Uso

Paleta aprovada para produtos com identidade visual azul, usada como referencia
recente em Ducal, Porto Estrela e GEOHER001/Herculano.

## Configuracao

Exemplo em `configs/clients/geoher001.json`:

```json
{
  "primary_hex": "#002060",
  "secondary_hex": "#5B9BD5",
  "highlight_hex": "#1F4E79",
  "palette_start_hex": "#002060",
  "palette_end_hex": "#DBE5F1"
}
```

## Indicadores tecnicos

Para EPT/CHOL:

```json
{
  "ept_good_hex": "#1F77B4",
  "chol_bad_hex": "#C00000"
}
```

## Observacoes

Evitar que todos os elementos fiquem na mesma intensidade de azul. Para series
empilhadas, usar paleta alternada/contrastada para preservar leitura.
