# Analises tradicionais de ictiofauna - C001 a C047

As planilhas tradicionais foram geradas com a base historica completa C001-C047.
As figuras com eixo de campanha foram exportadas por ano temporal, com corte agosto-julho.

- Ano temporal 2023: C001 a C012.
- Ano temporal 2024: C013 a C024.
- Ano temporal 2025: C025 a C036.
- Ano temporal 2026: C037 a C047; julho/2026 ainda nao entrou na base.

A taxonomia de saida apresenta Poecilia mexicana como Poecilia cf. mexicana.
Banco de dados, coordenadas e categorias ecologicas mestre nao foram alterados.
