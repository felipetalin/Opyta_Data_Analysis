# Prototypes

Experimentos visuais e metodologicos ficam aqui ate serem aprovados.

Quando um prototipo vira padrao:

1. mover a logica para `src/opyta_analysis`;
2. registrar a decisao em `docs/patterns/`;
3. atualizar `scripts/SCRIPT_CATALOG.md`;
4. manter o prototipo apenas como referencia historica ou remover se nao tiver
   valor de consulta.
