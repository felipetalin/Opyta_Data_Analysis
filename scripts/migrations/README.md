# Migracoes

Scripts de carga, SQL e correcao estrutural de dados.

Antes de rodar:

- conferir `.env` e projeto alvo;
- registrar o resultado em `outputs/_runs/` ou no README do projeto;
- manter arquivos SQL gerados dentro da subpasta da migracao;
- evitar misturar migracao unica de cliente com funcoes reutilizaveis.
